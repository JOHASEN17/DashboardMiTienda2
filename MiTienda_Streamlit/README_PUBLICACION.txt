DASHBOARD MITIENDA EN STREAMLIT

ARCHIVOS QUE DEBES SUBIR AL MISMO REPOSITORIO DE GITHUB:
1. dashboard.py
2. requirements.txt
3. LaTiendaCom_convertido.xlsx

PASOS:
1. En GitHub, abre el repositorio del proyecto.
2. Add file > Upload files y sube los tres archivos anteriores.
3. Pulsa Commit changes.
4. Abre https://share.streamlit.io/ e inicia sesión con GitHub.
5. En Create app, selecciona el repositorio y la rama donde guardaste los archivos.
6. En Main file path escribe: dashboard.py
7. Pulsa Deploy.

NOTAS:
- No se importa Flask; esta versión utiliza Streamlit directamente.
- El Excel debe estar en el mismo directorio que dashboard.py y llamarse LaTiendaCom_convertido.xlsx.
- Si el Excel contiene datos privados, no lo publiques en un repositorio público.
- Si aparece un nuevo error, abre Manage app > Logs y comparte el mensaje completo.
